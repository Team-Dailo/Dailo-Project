#  다일로 (Dailo) - 위치 기반 축제 이벤트 및 기능 테스트 플랫폼

**다일로**는 대학 축제와 같은 대규모 오프라인 현장에서 실시간 위치 정보를 활용해 사용자 체류를 인증하고, 시제품의 기술적 완성도를 검증하기 위한 **위치 기반 서비스(LBS) 테스트 플랫폼**입니다.

---

## 프로젝트 개요 (Project Purpose)
본 프로젝트는 창업 동아리 지원 사업의 일환으로, 개발 중인 위치 기반 서비스의 핵심 로직을 실제 환경에서 테스트하기 위해 기획되었습니다. 축제 참여자들에게 '경품 추첨 미션'이라는 게이미피케이션 요소를 제공함으로써 자연스러운 사용자 참여를 유도하고, 서비스 고도화를 위한 핵심 데이터를 수집합니다.

###  주요 테스트 목표
* **위치 인식 정확도:** 캠퍼스 내 특정 구역(Geofencing) 인식 및 유지력 확인
* **서버 부하 테스트:** 대규모 동시 접속자 발생 시 데이터 처리 및 안정성 점검
* **배터리 효율:** 포그라운드 서비스 구동 시 배터리 소모량 최적화 및 안정성 확보

---

##  주요 기능 (Key Features)

### 1. 지오펜싱 기반 이벤트 활성화 (Geofencing)
* 사용자가 설정된 축제 구역(캠퍼스) 내에 진입 시 앱이 이를 자동 인식합니다.
* 위치 권한(GPS)을 바탕으로 이벤트 참여 가능 여부를 판단하고 전용 팝업을 노출합니다.

### 2. 포그라운드 서비스 및 실시간 카운트다운
* **미션 지속성 보장:** 사용자가 앱을 종료하거나 백그라운드로 전환해도 미션이 중단되지 않도록 **Foreground Service**를 실행합니다.
* **실시간 알림창(Sticky Notification):** 스마트폰 상단 알림창에 사라지지 않는 타이머를 표시하여 사용자가 남은 시간을 상시 확인할 수 있게 합니다.

### 3. 미션 완료 및 데이터 보고 시스템
* 30분 체류 미션 성공 시, 포그라운드 서비스가 직접 "미션 완료" 푸시 알림을 발생시킵니다.
* 서버(DB)와 실시간 연동하여 미션 시작/종료 시점을 기록하고 부정 참여를 방지합니다.

### 4. 베타 테스터 피드백 루프 (Survey)
* 미션 완료 후 즉각적인 설문조사 기능을 제공하여 기술적 결함 및 UX 개선안을 수집합니다.
* **수집 데이터:** 위치 끊김 현상 여부, 서비스 장점(편의성/독창성/재미), 개선 필요 사항 등

---

##  사용자 참여 시나리오 (User Scenario)

| 단계 | 사용자 활동 | 시스템 작동 (핵심 기술) |
| :--- | :--- | :--- |
| **01. 진입** | 축제 구역 내 앱 실행 및 위치 확인 | Geofencing, GPS API |
| **02. 시작** | 축제 구역 진입시 카운트 시작| Foreground Service Start |
| **03. 유지** | 앱 종료 후 축제 관람 (30분 체류) | Sticky Notification Timer |
| **04. 완료** | 미션 완료 푸시 알림 확인 | Local Push Notification |
| **05. 보상** | 설문조사 참여 및 경품 응모 완료 | REST API, Survey Logic |

---

## 📈 기대 효과 (Expected Outcomes)

1. **기술 검증:** 실제 필드 테스트를 통한 위치 기반 알고리즘의 고도화 및 데이터 확보
2. **사용자 경험 개선:** 테스터 피드백을 바탕으로 한 서비스 페르소나 및 UX 정교화
3. **사업적 근거 마련:** 시제품 기능 테스트 참여 대가(기프티콘) 지급을 통한 정당한 사업비 정산 및 지원금 활용 명분 확보
