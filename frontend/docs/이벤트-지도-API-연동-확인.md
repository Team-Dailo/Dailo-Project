# 이벤트·지도 API 연동 확인 방법

## 1. 사전 조건

### 백엔드 실행
```bash
cd backend
./gradlew bootRun --args='--spring.profiles.active=local'
# 또는
./gradlew bootRun
```
- 서버가 **8080** 포트에서 떠 있어야 합니다.

### 프론트 API 주소
- **Android 에뮬레이터**: `.env`에 `EXPO_PUBLIC_API_URL=http://10.0.2.2:8080` (이미 설정됨)
- **실기기**: 같은 Wi‑Fi에서 `EXPO_PUBLIC_API_URL=http://PC의IP:8080` (예: `http://192.168.0.10:8080`)
- 주소 변경 후 **앱을 완전히 종료했다가 다시 실행**해야 반영됩니다.

---

## 2. 백엔드 API 직접 호출 (선택)

터미널에서 아래처럼 호출해 보면 백엔드가 응답하는지 확인할 수 있습니다.

```bash
# 지도 API (bounds 예시: 서울 근처)
curl "http://localhost:8080/api/events/map?swLat=37.4&neLat=37.7&swLng=126.8&neLng=127.2"

# 이벤트 상세 (id는 실제 DB에 있는 값으로)
curl "http://localhost:8080/api/events/1"
```

- **지도**: JSON 배열이 오면 정상 (빈 배열 `[]`도 정상).
- **상세**: JSON 객체 하나가 오면 정상.

---

## 3. 앱에서 확인

### 지도 탭
1. 앱 실행 → **지도** 탭 이동
2. 위치 권한 허용 후, 잠시 기다리면 현재 영역 기준으로 **마커**가 뜹니다.
3. **연동됨**: 백엔드에 해당 bounds 내 행사가 있으면 마커 표시, 없으면 마커 없음 (에러 아님).
4. **연동 안 됨**: 마커가 전혀 안 뜨고, Metro/터미널에 `events map failed` 또는 네트워크 에러 로그가 보일 수 있음.

개발 빌드에서는 Metro 로그에  
`[Event API] map ok, count: N`  
처럼 로그가 찍히도록 해 두었습니다. N이 0이어도 요청이 성공한 것입니다.

### 이벤트 상세
1. **홈** 인기 게시물, **행사 리스트**, **달력** 또는 **지도**에서 행사 하나 탭
2. 상세 화면으로 들어감
3. **연동됨**: 포스터·제목·날짜·장소·주최 등이 **로딩 후** 채워짐 (백엔드 데이터).
4. **연동 안 됨**:  
   - "이벤트를 불러올 수 없습니다" 메시지가 보이거나  
   - Metro에 `event detail failed` 로그가 보임.

개발 빌드에서는  
`[Event API] detail ok: {id}`  
로그로 상세 조회 성공 여부를 볼 수 있습니다.

---

## 4. 정리 체크리스트

| 확인 항목 | 방법 |
|-----------|------|
| 백엔드 8080 기동 | 브라우저에서 `http://localhost:8080` 또는 위 curl 호출 |
| 프론트 API 주소 | `.env`의 `EXPO_PUBLIC_API_URL` (에뮬: `10.0.2.2:8080`, 실기기: PC IP:8080) |
| 지도 연동 | 지도 탭 → 마커 표시 여부 + Metro 로그 `[Event API] map ok` |
| 상세 연동 | 행사 탭 → 상세 화면에 데이터 표시 + Metro 로그 `[Event API] detail ok` |

---

## 5. 자주 나오는 문제

- **마커가 안 뜸**  
  - 백엔드에 **위도·경도가 있는 행사**가 해당 bounds 안에 있는지 확인  
  - DB에 행사가 없거나, bounds 밖이면 마커 0개가 정상입니다.  
  - `curl`로 같은 bounds 호출했을 때 빈 배열이면 백엔드 기준으로도 0개입니다.

- **상세 화면 "불러올 수 없습니다"**  
  - 백엔드가 꺼져 있거나, 주소가 잘못됐거나, 해당 id 행사가 없을 수 있음.  
  - `curl "http://localhost:8080/api/events/1"` 로 같은 id 호출해 보세요.

- **실기기에서만 안 됨**  
  - `localhost`는 기기가 아닌 PC를 가리킵니다.  
  - 실기기에서는 반드시 **PC의 실제 IP**를 `EXPO_PUBLIC_API_URL`에 넣어야 합니다.
