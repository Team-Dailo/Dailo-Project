# 위치 권한 켜는 방법

지도 탭에서 **현재 위치** 버튼을 쓰려면 앱에 **위치 권한**이 허용돼 있어야 합니다.

## Android

1. **설정** 앱 열기
2. **앱** → **앱 목록**에서 이 앱 선택 (앱 이름: `app` 또는 프로젝트에서 설정한 이름)
3. **권한** 메뉴 들어가기
4. **위치** 권한을 **허용** 또는 **앱 사용 중에만 허용**으로 변경

또는 지도에서 **현재 위치** 버튼을 눌렀을 때 나오는 알림에서 **설정 열기**를 누르면 앱 설정 화면으로 바로 이동합니다. 거기서 **권한** → **위치**를 켜면 됩니다.

## iOS

1. **설정** → **개인 정보 보호 및 보안** → **위치 서비스** 켜기
2. **설정** → **앱 목록**에서 이 앱 선택
3. **위치**를 **앱 사용 중에 허용** 등으로 설정

## 앱에서 처음 열 때

앱을 처음 실행하거나 지도 탭에 들어갈 때 **위치 권한 요청** 팝업이 뜨면 **허용** 또는 **앱 사용 중에만 허용**을 선택하면 됩니다.
