# Dailo 앱 구현 기능 정리

> 프로젝트 전체(프론트엔드·백엔드·인프라)에 구현된 기능을 정리한 문서입니다.

---

## 1. 앱 개요

- **앱명**: Dailo
- **패키지명**: `com.dailo.app`
- **프론트엔드**: Expo (React Native) + expo-router
- **백엔드**: Spring Boot (Java), MySQL, JWT 인증
- **인프라**: AWS (Terraform), 도메인 `dailoapp.com` / `stage.dailoapp.com`

---

## 2. 탭 구조 (하단 5개)

| 탭 | 경로 | 설명 |
|----|------|------|
| 홈 | `(tabs)/home` | 메인: 인기 행사 캐러셀, 인기 게시글, D-Day 배너, 행사 알림 예약 |
| 달력 | `(tabs)/calendar` | 행사 달력 뷰 |
| 지도 | `(tabs)/map` | 네이버 지도 기반 행사 지도, 필터(날짜/카테고리/인기/거리/규모), 길찾기 |
| 게시판 | `(tabs)/board` | 카테고리(전체/후기/질문/자유), 글 작성·상세·댓글·좋아요·스크랩·공유·신고 |
| 마이페이지 | `(tabs)/mypage` | 프로필, 활동 기록, 즐겨찾기, 신고·차단, 관리자 메뉴 |

---

## 3. 인증·회원

- **회원가입/로그인**: 이메일·비밀번호, JWT(액세스·리프레시)
- **프로필**: 닉네임 수정, 프로필 이미지
- **로그인 검증 딥링크**: 앱 스킴(`app://`) 처리
- **관리자**: DB `role=ADMIN` 또는 `application.properties`의 `app.admin.emails` / `app.admin.user-ids`로 권한 부여

---

## 4. 행사(Event) 관련

### 4.1 사용자 기능

- **행사 목록/검색**: 키워드, 날짜 범위(startAt~endAt), 카테고리, 지역 등
- **행사 상세**: 제목, 기간, 장소, 설명, 이미지, 좋아요, 스크랩, 길찾기(네이버 지도 앱/웹), 알림 예약
- **지도**: 네이버 지도 SDK, 마커 클러스터, 필터
  - 날짜(최대 31일), 카테고리, 인기/추천, 거리, 규모
- **달력**: 월별 행사 표시
- **홈**: 인기 행사 캐러셀, D-Day, 인기 게시글
- **행사 알림**: 로컬 푸시로 행사 시작 전 알림 예약/해제
- **스크랩(저장한 축제)**: 행사 북마크
- **참여한 축제**: 서버에 기록된 참여 이력 조회

### 4.2 위치·체류 인증

- **체류 인증**: 행사장 반경 200m 내 진입 시 `/api/location/start`, 이탈 시 `/api/location/complete`로 참여 기록 저장
- **참여 중인 축제 카드**: 마이페이지에서 현재 체류 중인 축제 표시(타이머 등)
- **StaySession**: 체류 시작/종료 시간, 행사·회원 매핑

### 4.3 백엔드

- **Event**: 제목, 기간, 장소, 위도/경도, 카테고리, 규모(EventScale), 상태(EventStatus), 썸네일 등
- **EventLike / Scrap**: 행사 좋아요, 스크랩
- **EventController**: 검색, 상세, 목록 등
- **크롤러**: 외부 API 연동(FestivalCrawlerScheduler, FestivalCrawlerService), 연도·지역 설정
- **AdminEventController**: 행사 CRUD, 행사별 좋아요 수, 행사별 조회수(ClickLog 기반)

---

## 5. 게시판

- **카테고리**: 전체, 후기, 질문, 자유
- **후기**: 특정 행사 연결(행사 선택), 행사별 필터
- **글**: 작성, 수정, 삭제, 목록(페이지네이션), 상세
- **댓글**: 작성, 삭제, 목록
- **좋아요/스크랩**: 게시글 좋아요, 스크랩(저장한 게시글)
- **공지사항**: 공지 목록/상세(고정글), 미리보기 API
- **검색**: 게시판 내 검색
- **공유/복사**: 링크 공유, 클립보드 복사
- **신고**: 게시글/댓글 신고
- **엔티티**: Post, Comment, PostLike, Notice

---

## 6. 채팅

- **채팅방**: 목록, 생성, 채팅방별 메시지
- **메시지**: 발송, 목록(페이지네이션)
- **ChatRoom, ChatMember, ChatMessage** (RoomType, MessageType 등)

---

## 7. 알림

- **FCM**: Firebase Cloud Messaging으로 푸시 발송
- **푸시 토큰**: 기기별 등록/해제 (NotificationController, PushToken)
- **알림 설정**: NotificationSetting(회원별 온/오프 등)
- **알림 로그**: NotificationLog
- **스케줄러**: 예정 행사 알림(NotificationScheduler) 등

---

## 8. 로그·통계

- **클릭 로그(ClickLog)**: 행사 클릭 등 이벤트 로깅
- **조회수**: 행사별 조회수 집계(EventViewCountUpdateService 등)
- **검색 로그(SearchLog)**: 검색어 저장
- **인기 검색어/인기 클릭 행사**: LogController, LogService (상위 N개 등)
- **실시간 7일·30일 집계**: 관리자용 조회수/통계

---

## 9. 신고·차단

- **신고(Report)**: 게시글/댓글/회원 등 ReportType, ReportReason, ReportStatus
- **신고 처리**: 관리자 처리(ReportAction 등)
- **차단(Block)**: 회원 간 차단, BlockController, BlockCheckResponseDto
- **관리자**: AdminReportController, AdminBlockController(차단 관리, 검색)

---

## 10. 마이페이지 메뉴

### 10.1 활동 기록

- 참여한 축제
- 저장한 게시글
- 내가 쓴 게시글
- 좋아요한 게시글
- 댓글 단 게시글

### 10.2 즐겨찾기

- 저장한 축제
- 부스 즐겨찾기
- 알림 예약한 행사

### 10.3 신고·차단

- 차단 기록

### 10.4 기타

- 설정(settings)
- 위치 권한 안내(location-permission)
- 문의하기(contact)
- 이용 안내(guide)
- (비노출) 참여 서버 기록, 체류 미션 기록, 내 신고 목록 등

### 10.5 시범/특수 화면

- 체류 미션 기록, 참여 기록, 래플/쿠폼 목록 등 (화면 존재, 일부 비노출 가능)

---

## 11. 관리자 기능

- **진입**: 마이페이지 → 관리자 메뉴(ADMIN 또는 지정 이메일)

| 메뉴 | 화면/기능 |
|------|-----------|
| 행사 관리 | 목록, 상세, 추가/수정(폼·상세형), 행사별 좋아요 수, 행사별 조회수, 검색 |
| 회원 목록 | 목록, 검색(searchKeyword) |
| 차단 관리 | 차단 목록, 검색 |
| 신고 기록 | 신고 목록, 검색 |
| 신고 처리 | 신고 상세, 처리(승인/반려 등) |
| 게시글 관리 | 게시글 목록, 검색 |
| 공지사항 관리 | 공지 목록, 작성, 검색, 미리보기 API |
| 동기화 로그 | SyncLog 목록, 상세 |
| 수집 로그 | IngestLog 목록, 상세 |
| 크롤러 | AdminCrawlerController(크롤러 연동) |
| 업로드 | AdminUploadController(이미지 등) |

- **관리자 API**: AdminMemberController, AdminEventController, AdminReportController, AdminBlockController, AdminPostController, AdminNoticeController, AdminIngestLogController, AdminSyncLogController 등

---

## 12. 콘텐츠·설정

- **AppContent**: 앱 내 정적 콘텐츠(이용약관 등) ContentController, AdminContentController
- **시범 설정**: demo-settings(위치/기능 시범용)
- **이벤트 위치 선택**: 행사 등록 시 지도에서 위치 선택(event-location-picker)

---

## 13. 업로드·파일

- **S3**: 이미지 업로드(UploadController, FileUploadController, S3UploadService)
- **presigned URL**: 설정 가능 만료 시간
- **AdminUploadController**: 관리자용 업로드

---

## 14. 인프라·배포

- **Terraform**: `infra/terraform/live/stage` — VPC, ECR, Route53(dailoapp.com), ACM, stage 도메인 등
- **백엔드**: Spring Boot, MySQL, JWT, S3, Firebase Admin SDK(FCM)
- **프론트**: Expo, EAS Build(AAB 등), 네이버 지도(패키지명·웹 URL 등록)

---

## 15. 기타 구현

- **부스**: 부스 즐겨찾기(boothFavorite), BoothDetailModal, 저장한 부스 목록
- **SyncLog**: 동기화 시작/완료(SyncLogService, SyncLogStartRequestDto 등)
- **IngestLog**: 수집(크롤러 등) 로그
- **EventHistory / EventSource**: 행사 이력·출처
- **HealthController**: 서버 헬스 체크
- **EarlyCorsFilterConfig**: CORS 설정
- **SecurityConfig**: JWT 필터, 경로별 인가
- **GlobalExceptionHandler**: 전역 예외 처리

---

## 16. 프론트엔드 주요 서비스(파일)

- `auth.service` — 로그인/회원가입/토큰/프로필
- `event.service` — 행사 검색/상세/목록
- `board.service` — 게시글/댓글
- `notice.service` — 공지
- `chat.service` — 채팅방/메시지
- `scrap.service` — 행사 스크랩
- `report.service` / `block.service` — 신고/차단
- `log.service` — 클릭/검색 로그, 인기 검색어
- `location.service` — 체류 인증 start/complete
- `eventReminder.service` — 로컬 행사 알림
- `admin.service` — 관리자 API
- `content.service` — 앱 콘텐츠
- `savedPost.service` / `boothFavorite.service` — 저장 게시글/부스
- `geocoding.service` — 주소/좌표
- `festivalParticipationStorage` / `demoLocationStorage` — 참여 상태/데모 위치

---

이 문서는 코드베이스 기준으로 정리한 것이며, 비노출 메뉴나 시범 기능은 주석/설정에 따라 달라질 수 있습니다.
