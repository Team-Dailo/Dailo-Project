# Docker 백엔드 수정 반영해서 올리는 법

코드를 수정한 뒤 **그 내용이 반영된 백엔드**를 Docker로 쓰려면, **이미지를 다시 빌드**한 다음 컨테이너를 올려야 합니다.  
그냥 `docker compose up -d`만 하면 **예전에 빌드된 이미지**가 그대로 쓰입니다.

---

## 1. 수정 반영해서 백엔드 다시 올리기

**프로젝트 루트**에서:

```bash
cd c:\dailo\Dailo-Project
docker compose up -d --build mysql backend
```

- `--build`: 백엔드(및 필요한 서비스) 이미지를 **현재 코드 기준으로 다시 빌드**
- `-d`: 백그라운드 실행
- `mysql backend`: MySQL 먼저 띄우고, 그다음 백엔드 (이미 있으면 그대로 사용)

**백엔드만** 다시 빌드해서 올리고 싶다면 (MySQL은 이미 떠 있을 때):

```bash
docker compose up -d --build backend
```

---

## 2. 캐시 없이 완전히 새로 빌드하고 싶을 때

이전 빌드 캐시를 쓰지 않고 **처음부터 다시** 만들고 싶다면:

```bash
docker compose build --no-cache backend
docker compose up -d backend
```

한 줄로:

```bash
docker compose build --no-cache backend && docker compose up -d backend
```

---

## 3. 순서 정리

| 하고 싶은 것 | 명령 |
|--------------|------|
| 코드 수정 반영해서 백엔드 올리기 | `docker compose up -d --build backend` |
| MySQL + 백엔드 둘 다 올리기 | `docker compose up -d --build mysql backend` |
| 캐시 없이 백엔드만 새로 빌드 후 실행 | `docker compose build --no-cache backend && docker compose up -d backend` |
| 이미 떠 있는 백엔드만 재시작 (코드 반영 안 함) | `docker compose restart backend` |

---

## 4. 주의

- **`--build`** 를 붙여야 **최신 코드**로 이미지가 다시 만들어집니다.
- `.env` 등 **환경 변수**를 바꿨다면, `docker compose up -d --build backend` 다시 한 번 실행하면 됩니다.
- DB(MySQL)는 볼륨에 저장되므로, `mysql`을 다시 빌드하지 않는 한 데이터는 유지됩니다.
