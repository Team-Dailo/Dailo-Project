# dailoapp.com 배포 시 이미지(사진) 설정

로컬에서는 되는데 **dailoapp.com에 올리면 사진이 안 뜨는** 경우, 아래를 확인하세요.

---

## 로컬 vs 배포 차이

| 구분 | 로컬 | 배포 (dailoapp.com) |
|------|------|----------------------|
| 저장 위치 | 서버 디스크 `./uploads` | **S3 버킷** |
| 이미지 URL | `http://localhost:8080/uploads/파일명` | `https://dailoapp.com/static/uploads/파일명` |
| 필요한 설정 | 없음 | **APP_UPLOAD_USE_S3=true** + S3 권한 |

배포 환경에서는 **반드시 S3를 쓰도록** 해야 하고, 인프라에서 `/static/*` 요청을 S3(CloudFront)로 보내도록 이미 구성돼 있습니다.

---

## 1. 백엔드(ECS) 환경 변수

다음이 **반드시** 들어가 있어야 합니다.

- `APP_UPLOAD_USE_S3=true` → 업로드 시 S3에 저장
- `APP_UPLOAD_STATIC_BASE_PATH=/static` → API가 반환하는 경로가 `/static/...` (CDN과 일치)
- `AWS_S3_BUCKET` → 사용하는 S3 버킷 이름 (예: `dailo-prod-static-2026`)
- `AWS_REGION` → 예: `ap-northeast-2`

**Terraform:**  
`infra/terraform/live/prod/main.tf`와 `stage/main.tf`의 ECS `container_env`에  
`APP_UPLOAD_USE_S3`, `APP_UPLOAD_STATIC_BASE_PATH`를 추가해 두었습니다.  
인프라 반영 후 **ECS 태스크를 다시 띄우면** 적용됩니다.

---

## 2. S3 쓰기 권한

ECS 태스크 역할(IAM)에 **해당 S3 버킷에 대한 PutObject 권한**이 있어야 합니다.  
Terraform ECS 모듈에 `bucket_name`을 넘기면 보통 여기서 정책이 붙습니다.  
이미지 업로드 시 403 등이 나오면 이 권한을 확인하세요.

---

## 3. 프론트(앱) API 주소

앱이 **이미지 URL**을 `API_BASE_URL + path` 로 만듭니다.

- `path`가 `/static/uploads/xxx.jpg` 형태로 오면  
  → `https://dailoapp.com/static/uploads/xxx.jpg` 로 요청이 가야 합니다.
- 그래서 **배포 앱**의 `EXPO_PUBLIC_API_URL`은 **`https://dailoapp.com`** (또는 실제 API가 있는 같은 도메인)이어야 합니다.
- API는 `api.dailoapp.com`, 이미지는 `dailoapp.com/static` 이라면,  
  이미지용으로만 다른 베이스 URL을 쓰는 식으로 프론트를 바꾸지 않는 한,  
  **API와 이미지가 같은 도메인(dailoapp.com)** 에 있어야 합니다.

---

## 4. 적용 순서 요약

1. **Terraform**  
   - `APP_UPLOAD_USE_S3`, `APP_UPLOAD_STATIC_BASE_PATH` 추가됨  
   - `terraform apply` 후 ECS 서비스 업데이트(새 태스크 배포)

2. **백엔드**  
   - 위 환경 변수로 재배포되면, 새로 올리는 이미지는 S3에 저장되고  
   - API는 `/static/uploads/...` 형태로 path 반환

3. **앱**  
   - `EXPO_PUBLIC_API_URL=https://dailoapp.com` (또는 해당 도메인)  
   - 그 상태에서 이미지가 `https://dailoapp.com/static/uploads/xxx` 로 요청되는지 확인

4. **이미 올라간 예전 이미지**  
   - 예전에 로컬 디스크(`/uploads/...`)만 썼다면 S3에는 없을 수 있음  
   - 그건 배포 서버에 없으므로 **404가 정상**입니다.  
   - 새로 올리면 S3 + `/static/...` 로 뜨는지 확인하면 됩니다.

---

## 5. Postman으로 확인

- **업로드:** `POST https://dailoapp.com/api/upload` (multipart, 로그인 토큰)
- **응답:** `{ "path": "/static/uploads/xxx.jpg" }` 처럼 **/static/** 으로 시작해야 함
- **이미지 조회:** `GET https://dailoapp.com/static/uploads/xxx.jpg` → 200 + 이미지 내용

이렇게 되면 dailoapp.com에서도 사진이 뜨는 설정이 맞습니다.
