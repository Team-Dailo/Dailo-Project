# Android 앱 출시용 Keystore(.jks / .keystore) 만들기

앱을 스토어에 제출하려면 **릴리스 서명용 keystore**가 필요합니다.  
`.jks`와 `.keystore`는 같은 용도(키 저장)이며, 둘 다 사용 가능합니다.

---

## 1. Keystore 생성 (로컬에서 한 번만)

JDK가 설치된 PC에서 터미널(PowerShell 또는 CMD)을 열고 실행하세요.

### 1) 프로젝트 루트로 이동

```powershell
cd C:\dailo\Dailo-Project\frontend
```

### 2) keytool로 keystore 생성

아래 명령에서 **비밀번호**, **이름/회사 등**만 본인 값으로 바꿔서 실행하세요.

```powershell
keytool -genkeypair -v -storetype PKCS12 -keystore android-release.keystore -alias dailo-release -keyalg RSA -keysize 2048 -validity 10000
```

- `-keystore android-release.keystore`  
  → 생성할 파일 이름. `.keystore` 대신 `android-release.jks`로 해도 됩니다.
- `-alias dailo-release`  
  → 키 별칭. 나중에 서명할 때 이 alias를 씁니다.
- `-validity 10000`  
  → 약 27년 유효 기간 (스토어 제출에 충분).

실행하면 **키스토어 비밀번호**, **이름/조직/도시 등**을 물어봅니다. 모두 입력하면 `android-release.keystore` 파일이 생성됩니다.

### 3) .jks로 만들고 싶을 때

`.keystore` 대신 `.jks` 확장자를 쓰려면:

```powershell
keytool -genkeypair -v -storetype JKS -keystore android-release.jks -alias dailo-release -keyalg RSA -keysize 2048 -validity 10000
```

**중요:** 이 keystore 파일과 비밀번호, alias는 **한 번 잃어버리면 같은 서명으로 앱 업데이트가 불가능**합니다.  
반드시 **백업**하고, 비밀번호와 alias는 안전한 곳에 적어 두세요.

---

## 2. EAS Build에서 사용하는 방법

Expo EAS로 빌드할 때는 두 가지가 있습니다.

### 방법 A: EAS가 키를 관리 (가장 간단)

1. 처음 **production** 빌드할 때:
   ```powershell
   cd C:\dailo\Dailo-Project\frontend
   npx eas build -p android --profile production
   ```
2. “Would you like to create a new Android Keystore?” → **Yes** 선택  
3. EAS가 keystore를 만들어서 서버에 안전하게 보관하고, 이후 빌드부터 자동으로 사용합니다.  
   → **별도 .jks/.keystore 파일을 로컬에 만들 필요 없음.**

### 방법 B: 직접 만든 .jks / .keystore 사용

이미 위 1번처럼 `android-release.keystore`(또는 `.jks`)를 만들어 뒀다면:

1. **EAS credentials에 업로드**
   ```powershell
   cd C:\dailo\Dailo-Project\frontend
   npx eas credentials -p android
   ```
2. 메뉴에서 **Production** → **Keystore: Set up a new keystore** 또는 **Use existing** 선택  
3. 안내에 따라 **keystore 파일 경로**, **비밀번호**, **alias** 입력  
4. 이후 `npx eas build -p android --profile production` 하면 이 keystore로 서명됩니다.

---

## 3. 정리

| 목적 | 할 일 |
|------|--------|
| **EAS로만 빌드하고 키 관리도 EAS에 맡기기** | `eas build -p android --profile production` 실행 후 keystore 생성 시 **Yes** → .jks/.keystore 파일 따로 만들 필요 없음 |
| **직접 keystore 파일을 가지고 싶을 때** | 위 1번대로 `keytool`로 `android-release.keystore`(또는 `.jks`) 생성 → 백업 후, 2번 방법 B대로 `eas credentials`에서 등록 |

둘 다 **출시용 서명**에는 사용할 수 있고, **.jks이든 .keystore이든 하나만 있으면 됩니다.**
